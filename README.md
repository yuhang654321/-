## 2.0 / 2.1 / 2.2 / 2.3 / 2.4 / 2.5 / 2.6 / 2.7 / 2.8 / 2.9 / 3.0 / 3.1 更新：从一局游戏，变成一张战役地图

这次大版本保留了原来的塔防骨架、LLM 导演、YOLO 第三只眼和离线回退，主要改了十四件事：

1. **十一只奶龙科植物**：原来六只全部重绘成同一“奶龙科”脸型/角/肚子/小爪子，但每只都有独立剪影和道具；新增奶龙炮、吸尘奶龙、回旋奶龙、玉玺奶龙，以及 2.7 的双发嘴替。
2. **十五关战役 + 关卡选择主界面**：每关有独立舞台规则、星级、解锁链；基础 2–5 波，不到 4 分钟会触发加时赛。进度存 localStorage，不登录、不上传。
3. **摄像头修复**：权限诊断、设备选择、重新请求、明确的 Windows/浏览器排查步骤，以及“上传照片测试 YOLO”的后备路径。没有摄像头也能看完整个检测流程。
4. **奶龙博士升级**：支持连续对话记忆、时间/日期、算术、关卡信息、局面布阵建议和简单常识问答；算术/时间/关卡/建议走本地确定性工具，不靠模型胡编。
5. **傲娇开关**：喊他“妈妈/姐姐”再求他，会触发破例奖励；平时嘴硬但会记得上下文。
6. **敌人重绘 + 100% 笑到抱走**：五只敌人有独立外观；每只非 Boss 僵尸贴到奶龙花都会爆笑，把花抱回右边并留下 50 灵感。
7. **第三只眼好坏判词**：花 25% 同步率从 14 张判词里抽（8 好 / 5 坏 / 1 灾难）；可能天降怪物、全员加速，甚至全灭植物进入冷却，只能求妈妈救援。
8. **12×6 地图 + 一个半内鬼**：战场再扩到 12 列 6 行；单发嘴替正常打僵尸，双发嘴替专打友军，两者同路会先内讧。
9. **四分钟长局 + 十五套场景**：僵尸血量 ×1.55；不到 4 分钟自动加时；15 关各自有符合标题的配色、题字和场景道具（教室钟、食堂托盘、答辩聚光灯、玉玺、冕旒、王座）。
10. **双发嘴替 + 再减速**：2.7 新增双头内鬼，两个友军各吃一发；僵尸基础移速再压到 ×0.5。
11. **单发改正常 + 同路内讧**：2.8 单发嘴替单独时正常打僵尸；和双发同路时两人立刻停火，先互相解决对方，活下来的才恢复本职。
12. **会联网、会闲聊、会钓姐姐**：2.9 奶龙博士接入 Bing 检索，难题先查再答，回答逐字慢放；每次回复都用 +30 灵感钓你叫姐姐，光叫姐姐也有小额“叫声费”。

### 彩蛋：奶龙花笑到僵尸叛变

当僵尸走到 **奶龙花** 面前，会触发“笑到停战”：

1. 奶龙花先爆笑，僵尸也跟着笑到刀都掉了；

**每一只非 Boss 僵尸都会 100% 触发**，没有概率、没有冷却、没有次数上限。它不会被写进失败条件，Boss 不触发。

## 本地大模型：导演 + 助手

### 导演台本

每波开始前，`POST /api/director` 会带着当前关卡、波次、植物数、僵尸数、睡眠舱血量和舞台规则，请求 LM Studio 里的 Qwen2.5-7B：

```json
{"title":"...","line":"...","modifier":"sunstorm"}
```

后端校验 modifier，前端白名单执行。十种事件：
`sunstorm / fog / discount / speed / tank / heal / paper / gold / clone / blessing`（外加 `none`）。

导演台本在上一波清场后的休整期预取，把模型延迟藏起来；超时/JSON 不合法就用本地备份剧本，绝不让模型卡住主循环。

### 2.9 更聪明的奶龙博士：联网、闲聊、钓姐姐

`POST /api/chat` 现在支持：

- **连续对话**：前端保存最近 10 轮，后端把它们带进 prompt；
- **确定性工具**：`1+1 等于几`、`现在几点`、`第几关`、`我刚才问了什么` 由本地 Python 工具直接回答，不靠模型猜；
- **局面复盘与布阵建议**：`这关怎么打` / `该种什么` 会读取花/墙/输出数量、各行危险度、灵感和血量，给当前局面专用的建议；
- **联网检索**：它判断问题需要实时/外部事实时，会用 Bing 搜 3–4 条摘要，注入 prompt 后再让本地 Qwen 回答；回答下方会列出可点击来源。检索失败就明确说不确定，不编造；
- **慢慢回复**：前端不是瞬间刷出整段，而是像打字一样逐字显示；难题会先显示“联网查资料”再慢慢答；
- **闲聊/难题**：不再只回答固定游戏问题，也能聊新闻、学习、科技、电脑、冷笑话；LM Studio 在线时用完整 Qwen，离线时仍有本地工具和备用人格；
- **游戏动作**：`grant_sun / heal / spawn / bless / favor / tip / none`，后端做上限、冷却和关键词校验，模型不能召唤 Boss 或修改游戏外状态；
- **上下文**：关卡、波次、血量、灵感、植物/僵尸数、花/墙/输出数量、各行危险度、舞台规则、服务器时间都进入 prompt。

### 傲娇开关：喊妈妈/姐姐 + 求他

奶龙博士现在是非常典型的傲娇：嘴上“谁要帮你啊”“别误会”，但玩家只要在**同一条消息里**同时满足：

- 喊他 **妈妈 / 妈咪 / 娘 / 姐姐 / 姐**；
- 带 **求求 / 求你 / 拜托 / 帮帮 / 满足我 / 好不好 / 嘛**；

他就会破例：

| 你说 | 他做 |
| --- | --- |
| 妈妈求求你帮我 | +120 灵感、植物回血 40%、护盾 120 |
| 姐姐求求你救一下 | 所有植物回血 25% |
| 妈妈求求你给个盾 | 所有植物护盾 100 |
| 姐姐求求你放只僵尸 | 放一只滑板人（只一只） |

这是**本地确定性规则**，不依赖 7B 模型当天心情；LM Studio 离线时前端 fallback 也会执行。其他时候他仍然会嘴硬，但会记住上下文、算术、时间和关卡局面。

### 小费与“钓姐姐”

2.9 新增 `tip` 动作：

- 只喊 **姐姐/妈妈**（没有正式求他）时，会给 **20–35 灵感**的“叫声费”，默认 30；
- 每次正常回答结尾都会用一个小奖励引诱你叫姐姐，例如“+30 灵感”“开小灶”；
- 这不是无条件发钱：`tip` 后端会校验消息里必须出现姐姐/妈妈，且不能代替正式求救/加难度等动作。

## 自训练 YOLO：第三只眼

- 训练数据来自游戏自己的 SVG 精灵；2.1 的 `training/make_dataset.py` 已包含 10 种植物、5 只重绘敌人和早八皇帝。
- 类别：`plant / zombie / boss / sun / projectile`。
- 模型：YOLO11n，Ultralytics 8.4.187，CUDA 12.8。
- 线上权重：`models/abstract_yolo.pt`；首次加载有 warmup，之后单帧约 24–31ms。
- 游戏只裁切苗圃（846×520）再推理，避免卡牌和头像被误认；检测框加回 `(BOARD.x, BOARD.y)` 偏移叠到战场。
- 打开第三只眼后，识别数量积累「认知同步」，满槽触发随机「认知过载」。

### 抽象解读：花 25% 同步率抽一张判词

右侧第三只眼面板新增 **「抽象解读」** 按钮，也可以按 `X`。消耗 25% 同步率，从 **14 张判词**（8 好 / 5 坏 / 1 灾难）里抽一张。抽卡不是纯随机：约 7% 灾难、33% 坏、60% 好。

好技能：

| 判词 | 效果 |
| --- | --- |
| 导师凝视 | 全场僵尸僵直 2.4 秒 |
| 人群恐惧 / 时间倒流 | 僵尸后退 110 像素 |
| 万物皆盆栽 | 植物回血 35%，获得护盾 |
| 太阳能诈骗 | YOLO 把灵感认成 UFO，+110 灵感 |
| 论文暴雨 | 所有僵尸受到 160 伤害 |
| 第四面墙 | 植物获得 80 护盾 |
| 虚无主义 | 全场僵尸减速 3 秒 |

坏技能：

| 判词 | 效果 |
| --- | --- |
| 灵感税 | 没收 150 灵感 |
| 低血糖 | 所有植物失去 12% 生命 |
| 怪物派对 | 当场投放 5–7 只早八人 / 滑板人 |
| 全速前进 | 所有僵尸移速永久 +50% |
| 导师加课 | 终审导师提前进场 |

灾难技能：

| 判词 | 效果 |
| --- | --- |
| 全盘皆输 | 所有植物清空，全部植物卡冷却 15 秒；只能去求妈妈/姐姐 |

### 全盘皆输之后：只能求妈妈

灾难触发后：

- 植物全灭、卡组全部冷却 15 秒；
- 聊天按钮变成粉色 **「全灭！求妈妈救命」**；
- 普通治疗/护盾/加灵感都救不回来；
- 只有在聊天里同时喊 **妈妈/姐姐** 并求他，才会触发 **妈妈救援**：
  - 恢复最多 10 株之前的植物；
  - 所有植物卡冷却清零；
  - +200 灵感。

![全盘皆输](demo/doom-wipe.png)

![妈妈救援](demo/doom-rescue.png)

### 过载轮盘 + YOLO 幻觉

- 同步率满了不再固定“45 灵感 + 1.6 秒眩晕”，而是从同一组判词里随机抽一张，按 1.6 倍强度生效，额外 +45 灵感；**过载也可能是坏技能甚至全盘皆输**。
- 每次扫描有 14% 概率触发 **自动幻觉**：
  - 把僵尸认成学弟 → 全场僵直 1.2 秒；
  - 把植物认成盆栽 → 植物回血 12%；
  - 什么都没看见 → 虚无主义 +20 灵感。
- 判词会显示在第三只眼面板下方，并保留在 `visionVerdict` 里；悬停可看全文。

![第三只眼抽象解读](demo/third-eye-draw.png)

> 训练指标来自同分布合成验证集，不代表真实世界。新加入的植物沿用同一“奶龙科”视觉语言，实测仍能以 `plant` 检出；早八皇帝以 `boss` 检出；2.1 重绘后的五只敌人重新进入训练集。v2.1 验证：**mAP50 0.982 / mAP50-95 0.883 / P 0.995 / R 0.970**。

## 摄像头打不开？现在有三条路

现实裂隙（右侧面板 →「现实裂隙」）：

1. **摄像头**：优先用 `getUserMedia`；权限被拒、设备被占用、无设备、非安全上下文会分别给出提示，而不是静默失败。
2. **重新请求 + 设备选择**：可切换 Integrated Camera / 外接摄像头，重新走权限。
3. **上传照片测试**：选择一张本地图片，单帧跑 COCO YOLO11n，检测框照样叠回画面；照片只在本机 Python 进程中处理。

界面里还有四个诊断灯：`SECURE CONTEXT / MEDIA API / PERMISSION / CAMERAS`。如果摄像头被 Windows 隐私设置或微信/会议软件占用，按弹窗底部三步排查即可。**如果是在应用内预览窗口里打开，iframe 可能禁用摄像头；请复制 `http://127.0.0.1:8000` 到外部浏览器。**

## 快速开始

### 0. 环境

- Windows 10/11
- Node.js ≥ 20 + pnpm
- Python 3.12
- 可选：NVIDIA GPU + CUDA 12.8
- 可选：LM Studio，已下载 `Qwen2.5-7B-Instruct-1M`

### 1. 装依赖

```powershell
pnpm install
pnpm build
python -m pip install -r requirements.txt
python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128
```

### 2. 启动

```powershell
.\start.cmd
```

`start.cmd` 会绕过 Windows PowerShell 执行策略限制（终端里运行没问题；**双击**请用桌面快捷方式，避开 Smart App Control 对 cmd 的拦截）。也可以：

```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
# 或
python scripts/launch.py
```

打开 **http://127.0.0.1:8000**。

也可以直接双击桌面上的 **「奶龙协议」** 快捷方式：服务已在运行时只打开浏览器；服务没开时会自动启动本地栈。快捷方式图标使用你自己的 `AI_ Lab\专属图标.ico`。

### Windows 阻止 .cmd 快捷方式？

如果双击旧版 `.cmd` 快捷方式只看到“此应用已被阻止”，不是游戏坏了，而是 Windows 11 的 **Smart App Control / Code Integrity** 拦截了 `explorer.exe -> cmd.exe`：

```text
Event ID 3033: Code Integrity determined that explorer.exe
attempted to load cmd.exe that did not meet the Enterprise signing level requirements.
```

因此新版快捷方式不再指向 `play.cmd`，而是指向微软签名的 `powershell.exe`，运行 [`play.ps1`](play.ps1)：
- 先检查 `http://127.0.0.1:8000/api/health`；
- 已启动就只开浏览器；
- 没启动就用当前 Python 启动 `scripts/launch.py`，等后端就绪再开浏览器。

实测冷启动 4 秒进入游戏，事件日志不再出现 3033。

LM Studio 没开也能玩；标题/侧栏会显示 `FALLBACK`，导演和聊天切到离线人格。YOLO 模型未就绪时第三只眼会提示并自动关闭。

### 3. 开发模式

```powershell
# 终端 A
python -m uvicorn server.app:app --host 127.0.0.1 --port 8000
# 终端 B
pnpm dev   # http://127.0.0.1:5173
```

## 已知边界

- 合成数据只覆盖游戏域；`abstract_yolo.pt` 不是通用检测器。
- 摄像头需要浏览器/Windows 授权；没有授权也能用照片测试。
- 15 关全部手工编排，不是程序化无限关卡。
- 关卡进度只存在本机 localStorage；清浏览器数据会重置。
- 画面按 1600×900 等比缩放，移动端可点但未做专门竖屏布局。
