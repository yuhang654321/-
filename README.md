# -
欢迎
这是一个把“早八”做成塔防敌人的本地 AI 游戏：玩家在 12×6 的苗圃里种下原创奶龙植物，守住左侧睡眠舱；本地大模型负责当导演和军师，摄像头加自训练 YOLO 则组成“第三只眼”，实时观察战场并触发各种好坏难料的效果。
核心实现思路
整体架构：前端使用 Vite + TypeScript + Canvas 2D + DOM HUD，后端使用 FastAPI + Python；本地大模型通过 LM Studio 的 OpenAI 兼容接口接入 Qwen2.5-7B；视觉部分使用 YOLO11n + PyTorch/CUDA，单独训练了植物、僵尸、Boss、灵感、弹幕 5 个类别。关卡进度、三星评价存在浏览器 localStorage，不上传服务器。
核心逻辑
游戏主循环由 Canvas 定时更新，包含 15 个手工关卡、11 种植物、7 种普通敌人和 2 种 Boss；每关有独立场景、舞台规则、1/3 与 1/2 大波、4 分钟对局进程和最终 Boss。
第三只眼会把摄像头画面裁成苗圃区域，交给 YOLO 推理，得到检测框和类别计数；计数会转换成“认知同步率”，再随机抽取 14 张好坏判词——可能是全场僵直、天降怪物、全员加速，也可能是植物全灭、只能求妈妈救援。
奶龙博士不是单纯聊天框：/api/director 负责生成每波导演台本，/api/chat 负责问答和游戏动作；算术、时间、关卡信息、布阵建议走本地确定性工具，难题会先用 Bing 检索摘要再交给 Qwen，回答逐字显示并附来源。
傲娇行为是“规则 + 模型”双层实现：普通回复用小奖励引诱玩家叫姐姐；玩家真的喊“妈妈/姐姐”并求他时，由本地工具确定性触发奖励，不依赖模型当天心情。
难点与解决：
YOLO 环境与训练：一开始 Ultralytics 自动替换了 CUDA 版 PyTorch，训练直接掉到 CPU；后来重装 torch 2.11.0+cu128 / torchvision 0.26.0+cu128，并关闭会触发联网下载的 AMP，才稳定跑完训练。
模型输出不稳定：Qwen 有时不按 JSON 返回，或者擅自给玩家加资源；我加了严格 JSON 提取、动作白名单和关键词校验，模型不能召唤 Boss、不能无条件发钱。
摄像头不可用：浏览器权限、iframe 限制、设备占用都会让画面黑屏；我做了权限诊断、重新请求、设备选择，以及“上传照片给 YOLO 看”的后备路径，没有摄像头也能完整演示。
误检与体验平衡：YOLO 会把场景装饰认成植物或僵尸；通过苗圃裁切、置信度过滤、同步率阈值和随机判词，把误检转化成游戏机制的一部分，而不是直接报错。
节奏控制：早期一局太快，后来加入全局减速、12×6 地图、分段大波、4 分钟进程和最终 Boss；同时用统一出怪队列保证不会一次涌出好几只。
如何运行
安装依赖：pnpm install && pnpm build；Python 侧执行 python -m pip install -r requirements.txt，NVIDIA 显卡再装 CUDA 12.8 版 PyTorch。
启动本地模型：打开 LM Studio，加载 Qwen2.5-7B-Instruct-1M，在 
http://127.0.0.1:1234
 提供 OpenAI 兼容服务；不启动也启动项目：运行 .\start.cmd，或直接双击桌面「奶龙协议」快捷方式；浏览器打开 
http://127.0.0.1:8000
，首次使用摄像头时允许权限。没有摄像头可以在游戏内上传照片测试 YOLO。能用离线人格和本地工具。
